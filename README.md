<h1>Coordinate Converter</h1>

This is a coordinator converter for primarially maritime use. It is setup using PHPand jQuery

<h2>Motivation</h2>
This project started as a personal tool I created for my current job at the time. At work, we had a tool that would require a specific format of coordinates to be able to enter into the page and see where that position was in the world. However, clients and other sources would provide coordinates in varying formats. I made this tool as a way to quick and easily convert the format into the needed format for our internal use.

<h2>Quick Start</h2>
The files should be quick and easy to implement and utilize. Simply download the files, and upload to your webserver (apache was used for my purposes). 

<h2>Usage</h2>
This self contained site shall output coordinates you provide into the format of 00 00 00 N/S 000 00 00 E/W
